What is Event Watcher?

Event Watcher captures and displays analytics and marketing tracking events in real-time as you browse. It detects 500+ platforms including Google Analytics, Meta Pixel, Adobe Analytics, and more.

Side Panel vs DevTools

This Side Panel shows a quick overview of detected tracking tools grouped by category. For detailed event-by-event analysis, open DevTools (F12) and click the Event Watcher tab.

Reading the Tool List

  • Tool icon & name — The tracking platform detected
  • Request count — Number of requests sent by this tool
  • Category headers — Click to expand/collapse groups

Sorting Options

  • Category — Group tools by type (Analytics, Marketing, etc.)
  • A-Z — Alphabetical list of all tools
  • # — Sort by request count (most active first)

Controls

  • Search — Filter detected tools by name
  • Capture — Pause or stop event capture, or clear all detected tools
  • Categories & Tools — Browse all 500+ supported platforms
  • Settings — Theme, card size, default sort, and view mode preferences
  • Feedback — Report bugs, request features, or suggest missing tools
