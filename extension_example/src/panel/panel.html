AI

About AI features

Event Watcher uses BYOK (Bring Your Own Key) — your API key stays on this device, and every request goes directly to your chosen provider. Event Watcher never sees your key or your events.

Providers

  • Google Gemini — free tier, recommended to start. Any Google account can create a key at aistudio.google.com/apikey — no credit card.
  • Anthropic Claude — pay-as-you-go. Needs an API account at platform.claude.com with billing.
  • OpenAI — pay-as-you-go. Needs an API account at platform.openai.com with billing.
Subscriptions are NOT the same as API access.

Claude Max / Claude Pro covers claude.ai and Claude Desktop. ChatGPT Plus / Team covers chatgpt.com. Neither includes API access — the API is a separate product with its own billing. The Provider tab links to the right signup page for each.

What is sent to the provider

  • Parsed event data: platform, event name, parameters, consent state
  • Session structure: pages, script tree, consent timeline

What is never sent

  • Page HTML, cookies, or raw browsing history
  • Credentials detected in request payloads (redacted before send)
  • Your API key beyond the provider you configured

Permissions

AI features add no new permissions. Event Watcher already holds broad host access for tracking detection, so calls to your AI provider use the same access. Nothing is requested at install-time or on enable.

Privacy Policy

AI data-use disclosure

When you use AI features in Event Watcher, parsed event data from your current session is sent directly to the AI provider you configure (Google Gemini, Anthropic Claude, or OpenAI). Event Watcher acts as the transport only — the request leaves your browser over HTTPS to the provider you chose, using the key you provided.

✓ What is sent
  • Platform, event name, parsed parameters
  • Consent state at the time of each event
  • Page structure, script dependencies
✗ What is never sent
  • Raw page HTML or cookies
  • Full URLs outside captured requests
  • Credentials detected in payloads (redacted)
  • Your API key — stays on this device

You can remove your key at any time. This disclosure is shown once per key setup and is required by the Chrome Web Store.
